# 審議会の顔ぶれ

国の方針を話し合う審議会。委員の女性比率が政府目標（40％）に届かない会議はどこか。

**サイト：** https://arai-sarai-data.github.io/shingikai/

- データは公式の公開データを `fetch.py` が取得・検証して作ります（毎月自動更新）。
- 元データの形式が想定と違うときは公開を止め、前回の正しいデータを残します。
- 誤りの訂正・削除のご連絡：arai-sarai-data@proton.me

運営：洗井 浚（[@arai_sarai_data](https://x.com/arai_sarai_data)）
